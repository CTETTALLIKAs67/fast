Что посмотреть

/register и /login

Регистрация записывает пользователя в users.json. Вход работает в демо-режиме: у зарегистрированного пользователя принимается любой пароль.

/profile — домашняя

Личная страница. Анонимных посетителей она перенаправляет на форму входа.

/admin — ошибка 403

Секретная страница: её видит только пользователь с логином admin, остальные получают страницу «Доступ запрещён».

/api/me — JSON API

Возвращает текущего пользователя в JSON. А ещё откройте любой несуществующий адрес, например /no-such-page — увидите страницу 404.
